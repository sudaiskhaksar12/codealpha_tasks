# CodeAlpha Machine Learning Internship Tasks

This repository contains three machine learning projects completed for the CodeAlpha internship.

## Task 1: Credit Scoring Model
Predicts creditworthiness using the German Credit dataset. It compares Logistic Regression, Decision Tree, Support Vector Machine (SVM), and Random Forest models.

## Task 2: Emotion Recognition from Speech
Classifies emotions from speech audio using MFCC features and deep learning models with the RAVDESS dataset.

The best experimental CNN test accuracy achieved was 43.67%.

## Task 3: Handwritten Character Recognition using CNN
Recognizes handwritten digits and letters using Convolutional Neural Networks (CNNs).

- MNIST digit recognition accuracy: 98.91%
- EMNIST letter recognition accuracy: 92.81%

## Repository Structure

- `Credit_Scoring_Model/`
- `Emotion_Recognition_From_Speech/`
- `Handwritten_Character_Recognition_CNN/`

Each project folder contains its notebook, README, and relevant supporting files.

Raw audio files and virtual environments are excluded to keep the repository manageable. Refer to each project's README for setup instructions.
